# ADR 0043: 主题拥有配色算法、宿主链接端口与单一挂载契约

- 状态：Accepted
- 日期：2026-09-20
- 修订：ADR 0012、0022、0040、0041、0042

## 主题职责

M3 的算法、颜色、课程配色和生成入口完全属于 `theme-m3`，不再属于宿主或 ui-kit。插件提供静态颜色 JSON 和 ESM，ESM 注册 `m3-default` 及可选的 `resolveWallpaperColors({ pixels, mode, signal })`。输入为 RGBA 像素，输出为 Workbench 颜色及可选课程调色板。主题不直接修改宿主 DOM。宿主负责图片持久化、解码、降采样、取消过期任务、校验并应用结果。

取色仍限于 Profile 默认主题、自定义壁纸来源且主题提供能力。无图或计算失败保持该主题自身的基础颜色和调色板，不关闭偏好；条件失效才关闭。插件暂时缺席时不清除取色偏好。推荐图标始终随所选主题派生。取消或已替换主题的任务不得提交颜色。

颜色键与 Tailwind 映射是公共契约，不从 M3 算法生成。全部官方主题提供完整的基础颜色，宿主不保留 M3 后备色表。

## 构建与安装

官方插件声明可选 `prepareResources` 模块路径，其 `prepareResources(outDir)` 返回生成资源的相对路径，由通用构建器在隔离 Node 进程调用。插件自行生成资源，仓库没有主题专用算法。构建顺序为插件资源准备与发布、读取 Profile 默认主题的静态颜色并验证 ID/哈希/完整性、生成首屏 CSS、编译宿主与 PWA 预缓存。默认主题缺少静态颜色时构建失败。

首屏颜色来自默认插件，运行时主题接管后首屏规则失效。浏览器主题色和 PWA 清单配色从主题语义颜色派生。`vp run theme:generate` 仅准备当前默认主题并显式更新源码资源快照及首屏颜色，正常 dev/build 的生成资源和首屏 CSS 均写入忽略提交的目录。

纯 JSON 主题直接注册；同时提供 ESM 和颜色 JSON 时只由 ESM 注册颜色主题，激活后检查所属插件、主题 ID 和静态颜色一致性，失败进入现有回滚流程。JSON 不再次覆盖 ESM 贡献。M3 不再是纯 JSON 插件。

## 宿主链接与挂载

可选 `IHostLinks.getImportUrl(): string | null` 提供完整公开导入入口。Web 返回包含部署 base 的 `/s` URL。分享插件负责载荷和 hash；缺少能力时输出裸口令，非法 URL 报错。`encodeShareLink` 必须显式接收完整入口；长度估算包含实际链接基址。

挂载只返回 `{ update?(props): void; unmount(): void }`。出口验证形状，清理闭包持有本次实例，卸载异常不阻断后续挂载。`mount` 抛错前由插件清理已创建资源；成功返回后宿主负责卸载。

## 变更与验证

这是内部破坏性契约变更：移除 ui-kit M3 导出与宿主 M3 回退、改变 M3 分发形态、收敛挂载返回值、改变分享链接函数参数。数据库和分享线格式仍为 1，不迁移、不新增兼容别名。

验证覆盖分享入口与纯口令往返、非 M3 默认主题首屏、主题资源与 ESM 一致性、取色失败及过期任务、主题图标派生、真实浏览器挂载生命周期，并运行项目质量门禁与两种部署构建。

## 构建缓存与开发分发修订

构建准备由统一宿主入口编排，Vite 配置求值没有编译或写文件副作用。开发只准备开发市场，生产准备生产市场后执行一次宿主构建；资源、编译和发布分别复用，并校验缓存输入及产物摘要。资源准备入口经打包收集依赖后由新进程执行，避免 Node 模块缓存保留旧算法。

开发 catalog/manifest/资源全部由中间件提供；内容 revision 不变则不重复激活。HMR 追踪共享代码、CSS 扫描目录和资源输入，同插件串行，失败不发布，关闭服务器时释放监听与定时器。本次采用单次编译器，不引入常驻增量编译服务。

生产客户端收集宿主实际打包依赖并合并全部官方插件的许可证片段，直接输出许可证资产和 PWA revision，取消许可证预构建。开发使用运行时声明依赖清单，允许比生产多包含。外部 catalog/manifest 格式与数据版本不变；`prepareResources` 是内部破坏性契约变更，不提供旧签名分支。
