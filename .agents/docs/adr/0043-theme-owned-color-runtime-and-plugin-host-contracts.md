# ADR 0043: 主题拥有配色算法、宿主链接端口与单一挂载契约

- 状态：Accepted
- 日期：2026-09-20

## 主题职责

M3 算法、颜色、课程调色板和资源生成属于 `theme-m3`。插件交付静态颜色 JSON 和 ESM，后者注册主题及可选 `resolveWallpaperColors({ pixels, mode, signal })`。主题只计算颜色；宿主负责图片存储、解码、降采样、取消、校验和 DOM 应用。颜色键与 Tailwind 映射是公共契约，宿主不保留 M3 后备色表。

取色仅限具备能力的 Profile 默认主题搭配 custom 来源。无图或失败使用该主题基础外观，不关闭偏好；条件失效才关闭，主题临时缺席保留偏好。推荐图标始终随所选主题。替换或计算期间保留上一帧，过期任务不得覆盖新主题，新结果校验后接管。

## 构建与安装

插件可声明 `prepareResources` 模块，导出 `prepareResources(outDir)` 并返回生成资源相对路径。构建器打包入口以记录依赖，再在隔离进程执行；输出不回写源码。正常 dev/build 依次准备插件、验证默认主题静态颜色并生成首屏 CSS、构建宿主与 PWA；缺少合法默认颜色则失败。`vp run theme:generate` 是显式更新源码快照的入口。

首屏 CSS 来自默认插件，运行时主题接管后失效；浏览器主题色和 PWA 配色从语义颜色派生。纯 JSON 主题直接注册；同时有 ESM 和 JSON 时仅 ESM 注册，激活后校验所有者、ID 与静态颜色一致性，失败回滚。

宿主入口统一编排构建，Vite 配置求值不构建插件。资源、编译和发布分别缓存并校验输入与产物。开发中间件提供目录、Manifest 和 revision 资源；HMR 追踪共享代码、CSS 扫描目录和资源，同插件串行，失败不发布，相同内容不重复激活。生产先发布不可变资源，最后替换 catalog，保留旧 revision 供下载。

许可证在生产客户端打包时合并宿主实际依赖与全部官方插件片段，直接生成发布资产和 PWA revision；开发清单依据运行时依赖声明，可多包含依赖。

## 宿主链接与挂载

可选 `IHostLinks.getImportUrl()` 返回完整公开导入入口或 null。Web 入口包含部署 base；分享插件负责载荷和 hash，无入口输出裸口令，非法 URL 报错。`encodeShareLink` 显式接收入口，长度估算包含基址。

`ChronosMountable.mount` 只返回 `{ update?(props): void; unmount(): void }`。出口验证句柄并按实例清理，卸载异常不阻断后续挂载；mount 抛错前由插件回滚副作用，成功返回后由宿主负责卸载。

## 取舍

主题可替换算法，代价是默认主题必须同时提供静态首屏资源和一致的运行时贡献。上述接口直接维护当前结构，不保留旧 M3 导出、函数挂载返回值或旧资源准备签名。
