# ADR 0043：主题配色与宿主插件契约

- 日期：2026-09-20

## 主题职责

M3 算法、颜色、课程调色板和资源生成都由 `theme-m3` 管理。插件交付静态颜色 JSON 和 ESM。ESM 注册主题，也可以提供 `resolveWallpaperColors({ pixels, mode, signal })`。主题只负责计算颜色。宿主负责图片存储、解码、降采样、取消任务、校验结果和更新 DOM。颜色键和 Tailwind 映射属于公共契约，宿主不保留 M3 后备色表。

只有支持取色的 Profile 默认主题搭配 `custom` 来源时，才能从壁纸取色。没有图片或取色失败时，使用该主题的基础外观，不关闭用户偏好。只有条件失效时才关闭取色。主题暂时缺席时保留偏好。推荐图标始终跟随所选主题。替换主题或计算颜色时保留上一帧。过期任务不能覆盖新主题，校验通过的新结果才会生效。

## 构建与安装

插件可以声明 `prepareResources` 模块。模块导出 `prepareResources(outDir)`，并返回生成资源的相对路径。构建器会打包入口及其依赖，再在隔离进程中执行。生成结果不会写回源码。正常的 dev/build 流程会先准备插件，再验证默认主题的静态颜色并生成首屏 CSS，最后构建宿主和 PWA。默认颜色无效时，构建会失败。`vp run theme:generate` 用于明确更新源码快照。

首屏 CSS 来自默认主题插件。运行时主题接管后，这份 CSS 失效。浏览器主题色和 PWA 配色由语义颜色生成。纯 JSON 主题直接注册；同时提供 ESM 和 JSON 时只注册 ESM。主题激活后，宿主会校验插件归属、主题 ID 和静态颜色是否一致。校验失败时会回滚。

宿主入口统一编排构建。Vite 配置求值时不构建插件。资源准备、编译和发布分别缓存，并校验输入和产物。开发中间件提供目录、Manifest 和 revision 资源。HMR 会跟踪共享代码、CSS 扫描目录和资源。同一插件的任务串行执行；失败时不发布，相同内容不会重复激活。生产环境先发布不可变资源，最后替换 catalog，并保留旧 revision 供下载。

生产客户端构建时会合并宿主实际依赖和所有官方插件的许可证片段，并生成发布资产和 PWA revision。开发清单根据运行时依赖声明生成，因此可能包含更多依赖。

## 宿主链接与挂载

可选的 `IHostLinks.getImportUrl()` 返回完整公开导入入口或 `null`。Web 入口包含部署 base。分享插件负责载荷和 hash；没有入口时输出分享口令。非法 URL 会报错。`encodeShareLink` 显式接收入口，长度估算包含基址。

`ChronosMountable.mount` 只返回 `{ update?(props): void; unmount(): void }`。挂载出口会校验句柄，并按实例清理。卸载异常不会阻止后续挂载。`mount` 抛错前，插件负责回滚副作用；成功返回后，宿主负责卸载。

## 取舍

主题可以替换配色算法，但默认主题必须同时提供静态首屏资源和一致的运行时贡献。项目直接维护当前接口，不保留旧 M3 导出、函数挂载返回值或旧资源准备签名。
