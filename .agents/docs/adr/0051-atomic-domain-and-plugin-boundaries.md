# ADR 0051：领域修改与插件资源的原子边界

- 日期：2026-11-11
- 修订：ADR 0010 的公开状态、ADR 0046 的原生网络约束、ADR 0047 的插件资源提交

## 决策

课程修改通过 `core` 的语义动作，应用到最新一份已经保存的课表。宿主里的编辑、按周删除和拖动，不再提交从旧界面快照拼出来的整份课程列表。`IStorageService.mutateTimetable` 接收一个同步的修改函数。有 Dexie 时，在同一个读写事务里读取、修改和保存。没有这个端口的存储实现，退回到每个存储端口自己的队列；这条队列不保证不同进程之间也是原子的。用户明确发起的导入，仍然是整表覆盖。

引擎收到领域数据时会复制并冻结，作为可以信任的快照。公开状态、课表事件和徽标缓存都声明为深度只读。UI 控制器读的是引擎已经接受的快照，订阅端口不提供写方法。操作返回的独立结果，以及表单草稿，仍然可以编辑。读取状态时，不再把整份课表深复制一遍。某张课表删除提交之后，这份课表上还没发出的发布作废；清空则让所有还没发出的发布作废。之后的重建，以及其他课表上仍然有效的更新，还可以继续发布。

官方插件的界面通过 `controller.snapshot` 的公开订阅更新状态，不能靠直接读宿主控制器上的 Svelte rune，来建立跨 bundle 的响应关系。节假日界面和今日界面用同一种订阅方式。

插件图片在提交之前只留在内存里。图片、执行资源、安装元数据和更新准备引用，在同一个库事务里提交。事务按当前快照和准备快照里的最新引用回收图片。用户自己的壁纸不参与这次回收。运行时缓存的激活、安装和卸载共用一个操作协调器。协调期间如果外面又来了通知，就再跑一轮。迟到的激活按当前安装修订再核对一次，过期的实例撤掉。

原生 HTTP session 关闭底层的自动重定向。宿主逐跳检查 HTTPS 和声明过的域名，限制跳转次数并拒绝循环。跨来源时清除敏感请求头。Quality 增加了 Android 单元测试和原生编译，并按变更范围运行仪器测试和 iOS 无签名编译。

插件页面的控制器拥有订阅、请求和操作的生命周期。离开页面之后，不接受迟到的结果，也不再开始安装。目录或 Manifest 读失败时，显示失败和重试，不用一个空市场掩盖错误。

## 契约与验证

新增了按周删除课程和拖动课程两个动作。课程动作可以指定课表 ID。拖动返回实际移动了的课程，界面用提交之后的课程 ID 做过渡。公开状态和相关事件的类型收紧为只读。存储结构、分享格式、插件市场和原生更新的线协议不变。

回归覆盖这些情况：共享存储上的并发课程修改、失败队列的恢复、删除和清空之后的迟到发布、输入和状态引用彼此隔离、操作结果里嵌套的部分仍可编辑，以及插件激活和回滚期间的卸载与替换、图片提交失败后的事务回滚。模拟存储、事务回滚，和真实浏览器、原生编译、仪器测试，要分开报告。不能把其中一层的测试，说成所有平台都已经端到端验证过。

代理的内存限流仍然只约束单个实例，并用按顺序清扫的方式，避免每次请求都扫描全部客户端。整个部署共享的配额由网关或平台防火墙提供，不为此新增外部存储。
