# ADR 0051：领域修改与插件资源的原子边界

- 日期：2026-11-11
- 修订：ADR 0010 的公开状态、ADR 0046 的原生网络约束、ADR 0047 的插件资源提交

## 决策

课程修改通过 core 的语义动作应用到最新的持久课表。宿主编辑、按周删除和拖动不再提交从旧界面快照生成的整份课程列表。`IStorageService.mutateTimetable` 接收同步修改函数；Dexie 在同一个读写事务内读取、修改和保存。没有该端口的存储实现使用每个存储端口独立的队列作为回退，队列不承诺独立进程之间的原子性。显式导入保留整表覆盖语义。

引擎接收领域数据时复制并冻结可信快照，公开状态、课表事件和徽标缓存声明深度只读；UI 控制器读取引擎已接受的快照，订阅端口不暴露写方法。操作返回的独立结果和表单草稿仍可编辑。读取状态不重复深复制整份课表。删除提交后使该课表的迟到发布失效，清空使所有既有发布失效；后续重建和其他课表的有效更新仍能发布。

官方插件界面通过 `controller.snapshot` 的公开订阅更新状态，不能依赖直接读取宿主控制器的 Svelte rune 建立跨 bundle 响应关系。节假日界面与今日界面遵循同一订阅方式。

插件图片下载结果在提交前留在内存。图片、执行资源、安装元数据和更新准备引用在同库事务内提交，事务按当前与准备快照的最新引用回收图片，用户自定义壁纸保持独立。运行时缓存激活、安装和卸载共用操作协调器；协调期间的外部通知触发下一轮，迟到激活按当前安装修订复核并撤销过期实例。

原生 HTTP session 关闭底层自动重定向，由宿主逐跳校验 HTTPS 与声明域名，限制跳转次数并拒绝循环，跨来源清除敏感请求头。Quality 补充 Android 单元测试和原生编译，按变更范围运行仪器测试及 iOS 无签名编译。

插件页面控制器拥有订阅、请求和操作生命周期；离页后不接受迟到结果或启动安装。目录及 Manifest 读取失败显示失败与重试，不以空市场掩盖错误。

## 契约与验证

新增课程按周删除与拖动动作，课程动作可指定课表 ID；拖动返回实际移动课程，界面使用提交后的课程 ID 呈现过渡。公开状态及相关事件的类型收紧为只读。存储结构、分享格式、插件市场及原生更新线协议不变。

回归覆盖共享存储的并发课程修改、失败队列恢复、删除与清空后的迟到发布、输入与状态引用隔离、操作结果的嵌套可编辑性、插件激活及回滚期间的卸载和替换，以及图片提交失败后的事务回滚。模拟存储与事务回滚测试和真实浏览器、原生编译及仪器验证分别报告，不将单层测试当作所有平台的端到端证据。

代理内存限流继续仅提供单实例配额，并通过有序清扫避免每次请求扫描全部客户端。部署范围的共享配额由网关或平台防火墙提供，不新增外部存储依赖。
