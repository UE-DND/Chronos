# ADR 0020: 提取 codec-kit 共享编解码原语包

- 状态：Accepted
- 日期：2026-08-23

## 决策

`@chronos/codec-kit` 是普通共享库，提供 Deflate raw、Base64、CRC32、Varint、字符串池与周次位掩码原语。各编解码插件通过包依赖使用，构建时内联，不作为运行时插件装配。

周次位掩码统一为 `1 << (week - 1)`，支持 1–32 周，非法周次显式报错。原语失败时抛错，由调用方决定处理方式。插件拥有自己的载荷结构、版本信封、解压上限及课表转换。

## 取舍

共享原语避免分享链接和二维码出现位偏移、压缩格式不一致。放入宿主会导致反向依赖，放入 core 会扩大领域内核职责，运行时服务又会增加插件加载依赖，故独立成库。
