# ADR 0020：共享编解码基础库

- 日期：2026-08-23

## 决策

`@chronos/codec-kit` 是普通共享库，提供 Deflate raw、Base64、CRC32、Varint、字符串池和周次位掩码等基础功能。编解码插件通过包依赖使用这些功能。构建时，基础库会内联到插件中，不作为运行时插件装配。

周次位掩码统一使用 `1 << (week - 1)`，支持 1～32 周。遇到非法周次时明确报错。基础函数失败时抛出错误，由调用方决定如何处理。插件各自定义载荷结构、版本信封、解压上限和课表转换方式。

## 取舍

共享基础函数可以避免分享链接和二维码出现位偏移或压缩格式不一致。把它们放进宿主会形成反向依赖；放进 `core` 会扩大领域内核的职责；做成运行时服务会增加插件加载依赖。因此将它们独立成库。
