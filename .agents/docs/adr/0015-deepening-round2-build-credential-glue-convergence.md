# ADR 0015：插件构建与实例状态

- 状态：Accepted（凭据实现由 ADR 0017 取代）
- 日期：2026-08-22

## 决策

宿主和独立插件分别解析模块并构建 CSS。插件使用公共样式入口，不引用宿主私有样式。宿主根据插槽能力元数据渲染界面。高校规则由对应的数据源插件管理。

插件激活时，在对应上下文中创建实例状态；释放上下文时一并清理状态。这样可以避免重载或多个实例共享状态。标准定义入口见 [ADR 0027](0027-round6-architecture-subtraction.md)。

本轮曾尝试通用化 Web 凭据保险箱。该实现已由 [ADR 0017](0017-webauthn-credential-retirement.md) 移除。
