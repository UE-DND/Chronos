# ADR 0015: 架构深化收敛 — 构建隔离、凭据解耦、宿主胶水清理与插件规范化

- 状态：Accepted（凭据实现由 ADR 0017 取代）
- 日期：2026-08-22

## 决策

宿主与独立插件分别解析模块和构建 CSS；插件使用公共样式入口，不引用宿主私有样式。宿主通过插槽能力元数据渲染界面，高校规则归对应数据源插件。

插件实例的可变状态随激活上下文创建和释放，避免重载或多实例共享状态。标准定义入口见 [ADR 0027](0027-round6-architecture-subtraction.md)。

本轮曾泛化 Web 凭据保险箱，该实现已由 [ADR 0017](0017-webauthn-credential-retirement.md) 移除。
