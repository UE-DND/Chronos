# ADR 0031：引擎时钟与插件导航

- 状态：Accepted（静态 Profile 打包由 ADR 0042 取代）
- 日期：2026-09-01

## 决策

`DayClock` 由 `ChronosEngine` 独占。时钟按分钟边界调度，并通过 `time:tick` 向宿主和插件提供统一时间。引擎冻结时，时钟停止；引擎销毁时，时钟释放。恢复后，时钟立即同步并重新对齐分钟。页面恢复可见时，宿主调用 `refreshSystemTime`。`core` 不监听 DOM，冻结期间会忽略刷新。

预览只高亮调用方明确提供的节次。相关数据变化会触发今日课程查询。分钟变化只会重算内存状态。异步课程查询和配色计算都会阻止旧请求覆盖新结果。

插件通过可选的 `IHostNavigation` 打开宿主课程编辑，不硬编码 Web 路径。
