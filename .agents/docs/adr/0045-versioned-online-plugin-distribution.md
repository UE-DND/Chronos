# ADR 0045：按宿主版本在线分发官方插件

- 状态：Accepted
- 日期：2026-09-26
- 修订：ADR 0030 / 0042 的资源发布与目录选择

## 决策

GitHub Pages 是唯一官方在线分发入口，目录为 `https://ue-dnd.github.io/Chronos/plugins/releases/<宿主版本>/catalog.json`。官方插件仍随宿主统一版本构建。Release 只发布应用安装包，不提供另一套插件下载入口。源码继续放在 Monorepo。

全量市场输出到 `dist/plugin-market`。宿主构建清理旧静态资源，只复制当前 Profile 必需插件到 `static/official-plugins`。目录和 Manifest 使用相对地址，内置与远程资源使用同一份字节和摘要。默认主题首屏 CSS、资源校验、安装记录、生命周期、回滚和卸载保护保持不变。

Profile 补装及必需插件版本同步读取内置精简目录。商店与已安装可选官方插件同步读取固定宿主版本的远程完整目录。来源根据 origin、路径边界和插件 ID 识别。远程官方 Manifest 与宿主版本不一致时拒绝安装。外部 Manifest URL 安装保留，不参与官方版本同步。开发环境使用本地全量市场和 HMR。

PWA 只预缓存本地必需资源。已安装插件从数据库恢复，不新增远程资源持久化路径。网络不可用时可启动内置功能、使用缓存插件；不能安装新可选插件。没有可用默认主题时仍明确启动失败。

## 发布

正式目录只从 `vX.Y.Z` 标签发布，标签必须与宿主版本一致。产物分支 `codex/plugin-dist` 保存各版本快照、源码提交和文件摘要，不保存源码；源码分支不提交生成物。已有版本只允许相同提交、相同产物重试，不覆盖或删除历史版本，也不提供 `latest`。

Pages CI 合并历史目录与当前 default Profile 网站，一次部署所有版本；上线检查当前版本及一个历史版本的目录、Manifest 和代表性资源。Vercel 在 Pages 验证成功后发布。APK 发布前也必须确认对应插件目录已上线。回滚网站仍保留全部历史插件目录。

## 边界

数据库、Catalog 和线格式版本维持 `1`，直接维护当前结构，不增加旧目录别名或数据补迁移。开发数据不兼容时手动清空。首次迁移发布新版本，不重建旧标签，旧 APK 保留自身随包资源。

原生代码与服务端部署仍随各自宿主构建。下载 ESM 不会为安装包新增 Capacitor 原生能力。插件同进程执行且无沙箱；SHA-256 只校验完整性，不证明来源可信。
