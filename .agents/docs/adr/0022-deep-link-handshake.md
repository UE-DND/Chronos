# ADR 0022: 深链解析协议泛化与导出格式逻辑下沉至插件

- 状态：Accepted（导出入口由 ADR 0043 补充）
- 日期：2026-08-23

## 决策

宿主 `/s` 遍历已注册导入插槽，调用 `deepLink.fromLocation`，将首个匹配结果送入统一导入预览。未匹配时展示插件安装引导，不直接解析分享载荷。

插件拥有载荷提取、编码、长度估算与截断警告。完整公开入口由可选 `IHostLinks` 提供；无入口时导出裸口令，见 [ADR 0043](0043-theme-owned-color-runtime-and-plugin-host-contracts.md)。

## 取舍

深链格式随插件演进，宿主只保留入口与流程。缺少解析插件时可以降级，但不能直接完成导入。
