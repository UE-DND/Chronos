# ADR 0022：由插件处理深链格式

- 状态：Accepted（导出入口由 ADR 0043 补充）
- 日期：2026-08-23

## 决策

宿主的 `/s` 入口会遍历已注册的导入插槽，并调用 `deepLink.fromLocation`。宿主将第一个匹配结果交给统一导入预览。没有匹配结果时，宿主显示插件安装引导，不直接解析分享载荷。

插件负责提取和编码载荷、估算长度，并显示内容过长的警告。可选的 `IHostLinks` 提供完整公开入口。没有入口时，插件只导出分享口令，见 [ADR 0043](0043-theme-owned-color-runtime-and-plugin-host-contracts.md)。

## 取舍

深链格式由插件维护，宿主只负责入口和导入流程。缺少解析插件时，宿主可以显示安装引导，但不能直接导入内容。
