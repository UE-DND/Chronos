# ADR 0033：外壳保活与二级页面过渡

- 日期：2026-09-03

## 决策

根 Layout 中，`ShellRouteHost` 和二级路由出口是同级元素。进入二级页面时，一级外壳 DOM 继续保留。系统只冻结 `.shell-content` 的布局和绘制，并给外壳设置 `inert`，阻止用户交互。

`view-transition-name: page-root` 只用于二级页面。返回动画作用于 `.shell-root`。壁纸不在冻结范围内，见 [ADR 0039](0039-shell-wallpaper-compositor.md)。设置预览会等过渡结束后再绘制，避免同时渲染两份课表。

## 2026-11-07：转场生命周期收敛

外壳保活继续沿用。原先由 Layout、全局 gate 和动画控制器共同维护的转场状态，改由 Layout 创建的 `navigation-presentation` 实例管理，通过 Svelte context 共享。UI 只读取状态并报告路由和外壳就绪；冻结、后退位置和预览绘制由已提交路由与当前转场阶段派生。

每次导航只选择一种呈现方式：系统已执行转场、减少动态效果或无页面转场时直接提交；其余优先使用 View Transitions，原生 Android 或不支持该能力时使用 DOM 动画。方向从当前导航及 shallow 遍历上下文计算，不再提前写入全局变量。

每个导航会话拥有自己的动画资源和路由放行回调。新导航、失败及卸载统一结束旧会话，旧回调不能修改新会话。路由失败恢复来源状态；动画失败只结束视觉效果，不回滚已经提交的路由，也不阻塞导航。DOM 动画和启动预热继续复用现有实现。

## 取舍

返回时可以保留周次和滚动状态，并减少网格重建。保活会占用内存，因此控制器必须管理隐藏内容的状态和生命周期。
