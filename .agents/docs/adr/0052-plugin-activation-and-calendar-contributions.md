# ADR 0052：插件实例边界与可撤销日历贡献

- 日期：2026-11-13
- 修订：ADR 0028 的 Today 导航、ADR 0031 的插件时钟操作、ADR 0037 的统计归属、ADR 0043 的公共 UI 与样式契约、ADR 0047 和 ADR 0051 的插件持久化边界

## 实例和持久化

保留现有插件体系，时钟、错误日志和资源主题继续作为插件随宿主共同发布。当前只有安装和卸载，不增加停用开关。服务端和移动 handler 继续由构建装配。

每次激活创建独立 token 和 `ctx.signal`，上下文只属于这一实例。`getPluginContext` 只返回正在运行的实例，旧加载句柄不能释放同 ID 的新实例。停止立即 abort，撤销贡献和订阅，拒绝新动作与注册。迟到的 disposable 立即释放。已经受理的业务写入保留真实提交结果，卸载和替换等这些写入结束后再继续。

`apply` 读取缓存、准备实例和注册贡献，持久化写入在此阶段立即拒绝。宿主先提交安装记录，再接受实例并开放写入，最后发送 `plugin:loaded`。直接通过引擎加载时自动接受。可能写入的错误订阅和缓存整理在接受后启动，不增加候选写入暂存层。

插件 storage scope 绑定插件 ID 和安装修订。普通写入在同一数据库事务里核对安装记录和修订，阻止另一窗口中的旧实例在卸载、重装或升级后写回。卸载时，安装记录移除、资源回收和插件 JSON／二进制数据删除原子提交；失败时数据保留，恢复原运行时并报告失败。升级、重载和应用关闭保留缓存。

`updateJson(key, synchronousChange)` 在事务里读取最新 JSON 并同步修改，返回提交值。键订阅限定自己的命名空间；沿现有跨窗口通道广播提交后的键通知，接收方重新读取，不广播缓存正文。

## 插件能力与 UI

插件动作采用 `Omit<ChronosActions, 'setVirtualNow'>`。移除完整存储服务和发布核心事实事件的能力，只提供冻结的 `listTimetables`、`getTimetable`、`queryCourses` 查询视图。私有数据只能走自身 storage scope。

网络使用自动绑定插件 ID 的 `IPluginHttpService`，提供 `proxy(action, payload)` 和 `supportsServer(action)`。请求合并实例和调用者信号，直接请求使用既有域名规则。统计服务自动加事件名前缀和归属字段，错误捕获订阅自动清理。插件端不暴露 vault，宿主原生接口保留。

虚拟时钟由实例 lease 拥有。最后更新的有效覆盖生效；释放只移除自身覆盖，再恢复上一有效覆盖或系统时间。停止后的实例不能再次冻结时钟或清除新实例的覆盖。

公共 `ChronosUiView` 提供只读快照、翻译、日历解析和必要 UI 能力。插件页面、导入界面、横屏侧栏获得真实白名单对象和自身 `context`，不传完整 controller，不靠类型断言隔离。SchemaForm、预览和翻译共享组件使用同一 view。移除整包 `getAllContexts()` 透传；弹层历史、嵌套弹层父级和侧栏操作通过明确 props 跨越挂载边界，并随失败、重载和卸载清理。

## 日历贡献

核心保留 `CalendarHoliday` 算法输入，删除 `AcademicConfig.holidayCalendar` 及来源、同步时间等字段。节假日插件在自己的 `calendars` KV 中按课表、年份保存节假日、来源、时间和请求标识，运行时任务按激活实例创建。

`calendar.holidays` 贡献提供同步的 `getHolidays(timetable)`，只读取已发布的不可变快照。缓存载入或提交成功后替换同 ID 贡献。统一解析按插槽顺序合并，日期去重，同日保留首个提供者的标签；没有注册的缓存不产生效果。变化通过 `calendarRevision` 和 `calendar:changed` 发布。

激活先订阅键变更再读取、校验缓存，并用读取代次防止旧结果覆盖新结果。同课表后发请求拥有提交权，不同课表并行。同步开始时原子更新 `requestId` 并保留旧数据，网络完成后只有标识匹配者能合并最新年度缓存。保存失败保留上一成功效果；取消、卸载和被替代任务不进入离线 fallback，也不显示成功。请求目标不随课表切换，删除课表取消对应任务并整理孤儿缓存。缓存不能重建领域课表。

卸载立即撤销日历贡献，由宿主删除插件 KV，不遍历或改写用户课表。重新安装缓存为空，用户手动同步。保留的缓存可供升级、重载、回滚和离线冷启动恢复。

所有布局、实际课程查询、通知和小组件算法都显式接收必填 holidays，纯算法不读插件状态或存储。主课表、已有课表预览、Today 当前及全部课表使用统一日历解析，未导入的预览传空日历。通知和小组件监听日历变化，替换计划和快照，卸载后恢复被过滤的课程。

页面壳提前启动；外部派生服务等待插件恢复后首次发布，在升级、重载和回滚期间等插件操作协调器稳定，并在异步计算完成时复核日历代次。宿主关闭先停止外部服务，再释放插件。恢复或解析失败报告错误，保留上次成功输出，不用空日历覆盖。

## 导航、主题与装配

保留 `chronos://today`。底栏通过 `navigationIntent: 'today'` 声明意图，不依赖具体标签 ID。插件标签必须有当前 owner 和可挂载默认页面。选择顺序是匹配意图的有效标签、课表面板、有效默认启动标签、首个有效标签；沿用插槽排序，无目标不写入虚构 ID。只有课表面板回退会跳转当前周，冷启动 `defaultLaunch` 语义保留。

主题继续使用公共 `ui-*`、`text-*`、颜色、圆角、阴影、`course-capsule` 和减少动画约定。补充页面背景、导航标签／图标／文字、标题文字、弹层表面语义类。Arknights 只使用这些入口，不依赖内部布局类、Bits UI 属性、`h1` 或子元素组合。共享样式维护分隔线结构，主题通过缩进、宽度和颜色变量定制；分段控件和滑块计算使用同一 padding 变量。

删除 `registerImportTab`，调用方直接使用泛型 `ctx.registerSlot`。架构检查禁止手写宿主运行时直接导入业务插件，生成的 server／mobile 注册表仅允许对应 `/server`／`/mobile` 声明入口，保留构建装配和测试例外。

## 兼容与验证

这是插件 API 和内部课表结构的破坏性调整，宿主与官方插件同步升级，不保留旧 API 或旧字段读取。数据版本仍为 `1`，没有迁移链，不自动清空数据；不兼容开发数据手动清理。分享线格式、Manifest 线格式、原生链接和发行方式不变。

验证覆盖实例与存储竞争、时钟 lease、真实缓存持久化往返、跨窗口同步、取消及保存失败、全部日历消费者、导航回退、主题切换和真实插件挂载边界。`verify-plugin-storage.ts` 使用真实 IndexedDB 事务及跨窗口通知，`verify-mountable.ts` 验证页面运行时边界。异步渲染错误通过 mount 生命周期端口上报，由宿主释放该挂载的 UI 资源；旧挂载的错误回调受挂载 token 约束。单元与组件测试、浏览器挂载验证、PWA 回归、Web 与 Mobile 构建分别报告结果。
