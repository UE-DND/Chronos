# ADR 0041: Profile 装配默认主题与独立壁纸取色

> 2026-09-20 修订：主题配色算法归属、M3 ESM 分发、首屏资源与壁纸取色以 [ADR 0043](./0043-theme-owned-color-runtime-and-plugin-host-contracts.md) 为准。

- 状态：Accepted
- 日期：2026-09-20
- 修订：ADR 0026、0040
- 装配与分发细则由 ADR 0042 取代：全部主题从统一市场资源预安装，无静态内置加载。

## 决策

默认主题是 `theme-m3` 插件，贡献 `m3-default`；以纯 JSON 主题发布到官方插件市场并由 profile 预安装，颜色数据由同一生成链产出。已安装同 ID 插件时，市场显示已安装，不提供重复安装入口；未安装时可正常安装。主题贡献对象归插件，M3 基础颜色和生成算法归 ui-kit，宿主启动 CSS 与取色使用同一数据源。所有主题通过普通贡献应用流程渲染。

Profile 必填 `defaultTheme: { pluginId, themeId }`，提供者必须装配且启用。Codegen 校验配置并将提供者加入首屏加载集合；运行时检查主题存在、可选择及注册归属。显式未知 profile 或无效默认主题导致初始化失败，展示启动错误界面。宿主基础 CSS 不是合法配置的替代值。

引擎在装配前没有激活主题或默认主题。用户未选择主题时使用 profile 默认值，存储层不注入 M3。延迟恢复期间只临时回退，不覆盖偏好；确认主题已移除或禁用后保存 profile 默认主题。加载失败时保留可恢复的选择。默认主题提供者禁止普通卸载、禁用及替换，profile 整体释放和引擎销毁不受此限制。

## 壁纸与取色

“已安装主题”以单选列表选择 `visualThemeId`；“已安装主题”下方独立栏的取色开关独立控制 `wallpaperColorEnabled`，开启后覆盖当前主题配色。取色条件失效时同步关闭开关并保存，恢复所选主题外观；条件恢复后不自动重新开启。保留的主题继续作为 `theme` 壁纸来源；主题无图片时禁用“跟随主题”，显示“当前主题未提供壁纸”；保留已有来源偏好，切换到带壁纸主题后恢复可选。切换配色不修改壁纸来源或用户图片。取色开关当且仅当使用当前 Profile 默认主题且壁纸来源为 `custom` 时可用，不再检查实际壁纸是否存在；其他情况下禁用并将取色偏好保存为关闭；启动及跨标签页同步同样校正，外观管线不会应用不满足条件的取色覆盖。

取色模式清除主题覆盖，使用 M3 基础外观、宿主图标及动态课程颜色。无图片或提取失败保持基础外观，不修改选项。退出取色恢复主题颜色及推荐图标。取消过期任务，防止旧提取结果覆盖新选择。

## 数据契约与验证

Profile 默认主题结构、引擎装配前空状态及 ui-kit 主题贡献导出是破坏性内部变更。偏好版本保持 1，不增加升级链、旧格式别名或启动清理。覆盖非 M3 默认主题、延迟恢复、故障恢复、主题生命周期、动态配色及跨标签页图标同步，并验证各部署 profile 构建。
