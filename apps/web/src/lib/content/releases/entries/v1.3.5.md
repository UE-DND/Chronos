## 新特性

- 首次引导中的布局与长按演示新增暂停与继续控制，方便按需查看交互细节。

## 优化

- 恢复桌面端内容区域的原生滚动条，补全底部导航焦点样式、选择控件语义与表单键盘操作；完善插件及应用更新安装进度的无障碍名称与减少动画支持。
- 统一更新日志、开发者说明与法律条款的 Markdown 安全渲染，并在加载失败时提供重试入口。
- 隔离插件运行时实例、界面传参与私有存储，节假日缓存归入对应插件存储，卸载或替换插件时自动撤销日历贡献并原子清理安装数据。
- 统一主题语义样式入口并解耦 Arknights 主题适配，同步更新 Svelte、Tailwind CSS 与构建工具链依赖。

## 修复

- 修复课表周翻页在静止或微幅回正滚动时误拦截课程点击的问题，仅在真实翻页滑动后抑制误触。
- 修复「今日」入口的导航意图解析，自动过滤失效或未就绪的底部标签页。
- 修复插件页面在剩余高度内滚动受限、空课表在短横屏下无法滚动，以及引导页底部操作区与横屏手势区重叠的问题。
- 修复应用外壳与弹层未随可见视口变化而调整的问题，并抑制 iOS 主屏幕网页应用状态栏区域的滚动模糊。
