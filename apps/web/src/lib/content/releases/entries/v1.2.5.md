## 优化

- 将当前节次高亮改为正在上课的课程卡片描边，并同步更新课表与壁纸预览中的显示效果。
- 调整版本详情与软件更新页面的发布说明留白、段落间距和长文本换行，提升阅读体验。
- 按部署根路径隔离同源多实例的本地数据，并支持配置 Web 部署基础路径。
- 将官方插件程序资源与安装记录分开保存，清理不再引用的资源，减少安装状态更新时对程序正文的重复写入。
- 清除所有数据时恢复默认设置、移除额外安装的插件，并保留应用与当前 Profile 的预装插件。
- 成功保存课表后请求浏览器保留站点存储，降低浏览器自动清理本地数据的风险。

## 修复

- 修复课表宽度包含小数时周翻页定位偏移，以及窗口尺寸变化后可能跳到错误周次的问题。
- 修复纵向滚动时误触发周翻页回弹的问题，改善连续滑动与翻页中断后的定位。
