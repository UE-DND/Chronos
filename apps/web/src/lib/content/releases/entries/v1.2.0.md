## 新增

- Web、PWA 和 Android 支持自动检查更新：启动时检查，在线前台每 5 分钟检查一次，回到前台时检查过期结果，恢复联网时立即检查；离线或后台暂停，失败后自动重试。
- 发现新版本后，在「我的」页面的「关于」入口及「关于」页面的版本入口显示更新提示，仍由用户手动发起更新。
- Android 应用图标支持系统深色模式，并为 Android 13 及以上提供主题图标轮廓，需桌面支持并开启主题图标。

## 优化

- 重设计应用图标，以三色 C 形色带结合时钟指针，统一网页、PWA、Apple 和 Android 图标。
- 将「我的」页面中的「应用与支持」分组固定在其他分组之后。
- 上移课表周指示器。

## 修复

- 修复更新检查超时或异常后检查状态未正确恢复，以及自动检查与手动检查可能重复发起请求的问题。
- 修复历史 Android 发布记录阻断新版本更新信息发布，以及发布重试时因构建配置不一致导致已有 APK 校验失败的问题。
