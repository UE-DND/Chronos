## 新增

- 首次启动时显示配置引导，并提示将应用安装到主屏幕。
- 知行理工在线导入支持选择校区，并读取对应的节次时间。
- 支持生成课表分享链接，并从链接导入课表。
- 新增课程日期和时间输入控件，支持选择日期、今天和清除日期。

## 优化

- 离线时保留应用外壳，并显示网络状态。
- 缩短 PWA 页面导航等待网络的时间。
- 表单页面统一输入框和操作区布局。

## 修复

- 修复部分设备上日期选择器无法响应的问题。
- 凭据过期或 WebAuthn 不可用时，改为显示可继续操作的提示。
- 修复 GitHub Pages 子路径下页面跳转和资源加载异常。
