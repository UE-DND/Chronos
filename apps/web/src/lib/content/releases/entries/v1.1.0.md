## 新增

- 支持 Android 原生移动端应用，提供触觉反馈、安全区边距沉浸式适配与原生剪贴板能力。
- 接入 Android 原生应用内更新通道，支持检测最新版本并一键拉起系统安装器。
- 官方插件支持按宿主版本远程目录按需下载与离线持久化缓存，有效精简安装包体积。

## 优化

- 完善 PWA 离线资源与页面版本门禁机制，避免应用更新时的跨版本资源错配。
- 引入官方插件生命周期时序协调器，彻底消除安装、卸载与热重载交错时的并发竞态。
- 全面规范 Svelte 5 组件与运行库类型约束，提升界面交互流畅度与稳定性。
