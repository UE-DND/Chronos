## 新增

- 提供 Android 应用，支持触觉反馈、安全区适配和系统剪贴板。
- 可以在 Android 应用内检查新版本，并打开系统的安装界面。
- 官方插件按当前应用版本按需下载。已经安装的插件可以离线使用，安装包不再带上全部插件。

## 优化

- 收紧 PWA 离线资源和页面版本的检查，避免更新时用到另一版的页面或缓存。
- 调整插件安装、卸载和热更新的先后顺序，避免这些操作交错时互相覆盖。
- 收紧界面组件的类型约束，减少因此出现的状态错误。
