## 新增

- 提供 iOS 客户端，使用与 Android 相同的课表界面，通过可自签的 IPA 分发，不上架 App Store。最低系统版本为 iOS 17.4，Bundle ID 固定为 `org.uednd.chronos`。
- iOS 检查独立的更新源。确认后先准备已安装的可选官方插件，再下载并校验 IPA，然后交给当前自签工具安装。应用不能在应用内覆盖安装。
- 覆盖安装必须保持 Bundle ID，并用同一个 Apple ID 签名，应用数据才会保留。Bundle ID 被修改时，更新页进入阻断态，不提供下载。
- 首次安装该版本仍需手动安装 IPA。IPA 尚未发布时，iOS 只显示更新源错误，不会改用 Android 安装包。

## 优化

- 调整明暗模式配色。
- 统一设置分组标题的缩进，以及行的按下与焦点状态。
- 扩大「字体大小」滑块的拖动热区。点按轨道空白处仍不会改变字号。

## 限制

- iOS 暂不支持教务在线导入、精确闹钟和桌面小组件。
