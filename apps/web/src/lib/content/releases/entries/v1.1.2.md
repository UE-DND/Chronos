## 新增

- Android 新增「今日课程」桌面小组件，显示课程时间、地点和上课状态，点击可打开应用的今日页面。
- Web 二级页面支持从左侧边缘滑动返回。
- Android 和独立安装的 PWA 增加页面滚动到顶、到底时的边缘提示。

## 优化

- 优化课表按周滑动的跟手效果和松手后的翻页动画，以及移动端页面返回转场。
- 调整顶部安全区间距和触觉反馈强度，精简「我的」页面入口展示与顺序。
- 简化插件中心的体积、安装按钮和状态展示；移除启用开关，已安装且兼容的插件自动启用，需要确认兼容性时仍会提示。
- 插件安装进度随资源下载更新，并区分下载与校验阶段。

## 修复

- 修复切换主界面标签时，未激活面板仍可能显示的问题。
- 修复插件下载和壁纸解码超时、取消后立即重试时的任务冲突，以及资源校验失败后重试仍命中损坏缓存的问题。
- 修复插件安装完成后因窗口间同步失败而误回滚，以及跨窗口操作误确认插件兼容性的问题。
