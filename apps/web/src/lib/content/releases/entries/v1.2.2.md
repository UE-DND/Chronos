## 优化

- 统一实际课程安排查询，提升课表、「今日」、课前提醒和 Android 小组件对调课、停课等安排的显示一致性。
- 优化课表周次滑动与长按拖动课程的状态管理，改善拖动保存期间的预览和重复操作处理。
- 调整「我的」页面设置项顺序，将「反馈设置」移至「显示设置」之前。

## 修复

- 修复连续导入分享课表时可能覆盖已有课表的问题。
- 修复「今日」展示多个课表时，课程时间、上课状态和课前倒计时未按各自课表作息计算的问题。
- 修复 Web 应用更新中重复操作和中断恢复之间的冲突，完善更新准备数据与插件资源的清理。
- 修复应用初始化中断后可能残留事件监听或继续触发安装提示的问题。
- 修复原生安全区在横竖屏切换后错位的问题；布局优先采用原生 inset，并以浏览器环境值作为回退。
