## 优化

- 加强 Web 代理的地址校验与移动端更新链接校验，拒绝内网地址和带凭据的更新链接。

## 修复

- 修复未授予通知或精确定时权限时仍尝试发送课前提醒的问题。
- 修复 Android 7 上恢复安装会话失败，导致应用内更新无法继续的问题。
- 修复 Web 端更新准备状态缺少有效期时被误判为过期，导致更新无法安装的问题。
- 修复官方插件构建缓存未记录构建期间的文件改动，可能复用旧产物的问题。
