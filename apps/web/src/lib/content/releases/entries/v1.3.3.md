## 修复

- 多个窗口同时改同一张课表时，编辑课程、按周删除和拖动都会按最新保存的内容执行，不再用旧页面上的课程列表覆盖其他窗口的修改。删除课表或清空数据之后，还没完成的刷新不会把旧课表恢复回来。
- 课表已经保存，但后面的刷新或切换失败时，会说明保存已经完成，并提示重新加载后再查看。读取本地课表失败时，不再显示成还没有课表，启动时也不会因此改选另一张课表。
- Web 端内置的插件清单失效时，会尝试从当前应用版本已经发布的目录恢复，避免读到其他版本的资源，导致默认主题打不开。
- 插件的主题图片、程序和安装记录会一起保存，失败则全部回滚。其他窗口正在安装、更新或卸载时，会重新核对插件版本，避免已经卸载或替换掉的旧插件继续运行。
- 插件配置只有保存成功之后才会更新。插件界面、配置或市场目录加载失败时显示错误，并可以重试。离开插件页之后，迟到的请求不会再开始安装。
- 「今日」和节假日页面会跟着课表与设置变化。今日课程查询失败时显示失败，并可以重试，不再把读失败显示成当天没有课。
- 知行理工在线导入和分享导入会区分网络、登录和数据格式问题。只有已经识别出的临时网络故障会重试，原来的失败原因会保留。
- 修复底部弹层向上拖动后悬空，以及往回滑时被误关闭的问题，并减少 iOS 主屏幕网页应用在横屏时侧栏多出来的安全区空白。
- 移动端处理网络和更新错误时，清理资源失败不会掩盖原来的更新错误。Android 访问教务系统时会逐次检查跳转地址，拒绝非 HTTPS、未声明的域名和循环跳转；跳到其他网站时会去掉认证信息。

## 优化

- 调整插件代理的限流清理，以及开发时插件热更新的调度。
- 更新 Vite+ 至 1.6.0，并升级 Node.js 和部署工具。浏览器回归按历史耗时分片，发布检查增加 Android 原生测试和 iOS 无签名编译。
