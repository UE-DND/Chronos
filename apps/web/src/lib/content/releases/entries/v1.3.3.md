## 修复

- 多个窗口同时修改同一课表时，课程编辑、按周删除和拖动会基于最新保存的课表执行，避免覆盖其他窗口的修改。删除课表或清空数据后，尚未完成的刷新不会恢复旧课表状态。
- 课表已保存但后续刷新或切换失败时，明确提示保存已完成，并提供重新加载后的查看指引。读取本地课表失败不再被当作没有课表，启动也不会因此切换到其他课表。
- Web 端预安装插件清单失效时，尝试从当前应用版本对应的已发布目录恢复，避免读取到其他版本的资源而导致默认主题加载失败。
- 插件主题图片、执行资源和安装记录一并保存，失败时回滚；跨窗口安装、更新和卸载期间重新核对插件版本，避免已卸载或已替换的旧插件再次运行。
- 插件配置仅在保存成功后更新。插件界面、配置或市场目录加载失败时显示错误并提供重试；离开插件页后，迟到的请求不会继续启动安装。
- 今日课程和节假日界面随宿主课表与设置变化更新。今日课程查询失败时显示失败状态并提供重试，不再将读取失败显示为当天无课。
- 修正知行理工在线导入及分享导入的错误识别，区分网络、认证和数据格式问题；仅对已识别的临时网络故障重试，并保留原始失败原因。
- 修复底部弹层向上拖动后悬空，以及回滑时误关闭的问题；减少 iOS 主屏幕 PWA 横屏时侧栏多余的安全区留白。
- 加固移动端网络与更新错误处理，避免资源清理失败覆盖原始更新错误。Android 原生教务请求逐次校验跳转地址，拒绝非 HTTPS、未声明域名及循环跳转，并在跨来源跳转时移除认证信息。

## 优化

- 优化插件代理限流清理和开发时的插件热更新调度。
- 更新 Vite+ 至 1.6.0，并升级 Node.js 与部署工具链。浏览器回归按历史耗时分片，发布检查补充 Android 原生测试和 iOS 无签名编译。

## 兼容性与限制

- 现有课表、偏好设置、分享格式和插件市场格式无需迁移。
- 插件读取的课表、偏好设置、事件中的领域数据及课程徽标改为深度只读，不能直接修改宿主状态；需使用课程与配置动作提交修改。UI 快照订阅接口仅提供读取能力，插件界面应通过 `controller.snapshot.subscribe` 接收更新。
- `timetable:updated` 的课表参数可能为 `null`，插件需处理课表被删除或数据被清空的情况。创建、导入和更新课表后的刷新失败通过 `timetable:followUpFailed` 单独报告；删除结果在 `followUpFailed` 为 `true` 时包含原始 `cause`。
- 开发与构建环境改用 Node.js 26.13.0 LTS，不再支持 Node.js 24。
- iOS 仍需下载 IPA 后使用自签工具覆盖安装，并保持原 Bundle ID 和同一 Apple ID。教务在线导入、精确闹钟和桌面小组件仍不可用。
