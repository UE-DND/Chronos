## 一、服务说明

1. Chronos 是一款基于渐进式 Web 应用（PWA）技术的本地优先（Local-First）课程表管理工具，旨在帮助用户高效、便捷地查看、编辑与管理个人课程及学术日程安排。
2. 本软件以开源形式发布，源代码托管于 GitHub（[UE-DND/Chronos](https://github.com/UE-DND/Chronos)），遵循 Apache License 2.0 许可协议。
3. 本软件主要功能与服务包括但不限于：
   - **多课表管理：** 课程表的创建、重命名、编辑、切换与删除，支持为不同课表独立设置学期起始日、周数范围及校区节次时间；
   - **课程与日程展示：** 按教学周及网格视图浏览课程安排，支持跨周拖拽筛选、周次状态切换及课程时间冲突检测提示；
   - **导入与同步机制：** 支持通过分享口令、二维码图片、教务文件解析导入，或通过已安装的数据源插件连接第三方教学管理系统进行数据同步；
   - **导出与分享：** 支持将课表编码导出为自包含分享口令或二维码图片，以便在受信任的设备或用户间流转；
   - **模块化插件生态：** 提供官方插件目录，支持浏览、安装、启用、配置与卸载扩展（涵盖外观主题、数据源、编解码器、实用小工具等），并支持通过合规的 manifest 链接安装插件；
   - **个性化与外观设置：** 支持亮暗色主题模式切换、语义化品牌配色方案、自定义图标主题、课表背景壁纸（含主题壁纸、自定义上传图片、裁剪、透明度与虚化调节及本地壁纸智能取色）与操作触感反馈；
   - **日程提醒与辅助视图（由工具插件扩展）：** 当安装相应插件时，支持今日课程聚合概览、课前准备倒计时提醒，以及法定节假日与调休排课标记展示；
   - **渐进式 Web 应用（PWA）：** 支持安装至本地主屏幕作为独立应用运行，支持离线访问本地已缓存内容，并在检测到新版本时提供安全更新提示。
4. 本软件**不提供**独立的用户注册或中心化账号体系。除特定数据源插件可选的服务端网络代理请求及插件静态资源下载外，您的全部业务数据与配置均保存在您本人的设备本地存储中。
5. 我们提供的官方托管版可能使用第三方分析服务（PostHog）统计去标识化的功能使用情况，以改进本软件。未配置分析密钥的实例（含 GitHub Pages 静态版及自行部署版本）不会启用该功能。详情请参阅《Chronos 隐私政策》。

## 四、数据导入、导出与本地存储

1. **导入方式与解析：** 本软件支持通过分享口令、二维码图片或上传教务文件导入课表，并支持通过已安装的数据源插件获取数据。除特定插件可选的服务端网络代理中继外，所有本地文件解析、图片二维码识别均在您的设备本地运行时完成，不向服务端上传原始文件。通过外部深链（如 `/s#...` 落地页）打开本软件时，链接参数在浏览器端本地解析并引导导入。
2. **导出分享与端到端私密性：** 本软件允许您将当前课表导出为分享口令或二维码图片。导出内容仅包含课程结构、日程时间及学术配置等纯业务数据，**绝不包含**您的第三方账号、密码或任何认证凭据。分享口令基于 URL 哈希（Fragment）承载，根据标准 Web 规范，该部分数据不会随 HTTP 请求发送至 Web 服务器，确保课表内容在分享链路中的端到端私密性。
3. **本地优先存储规则：** 您确认并同意，导入或手动创建的课表数据、学术偏好、外观主题、壁纸资源、已安装插件记录及插件命名空间配置均存储于您本地设备的浏览器存储空间（包括 IndexedDB、localStorage 及 sessionStorage）。官方托管版启用使用统计时，由统计 SDK 生成的去标识化标识符亦存于 localStorage。「关于 → 清除所有数据」会清空 Chronos 自身的本地数据库与存储项，但不会删除第三方统计 SDK 存留于浏览器中的设备标识符；如需彻底清除，请在浏览器设置中清除本站点的全部网站数据。
