# Chronos 隐私政策

**生效日期：2026 年 9 月 24 日**

Chronos 开源项目维护团队（由项目发起人 UE-DND 及项目贡献者组成，以下简称「项目团队」或「我们」）深知个人隐私与信息安全对您的重要性。本隐私政策旨在向您详尽说明 Chronos（以下简称「本软件」）如何处理您的个人信息，包括信息的产生场景、存储位置、保护机制及您所享有的控制权利。

请您在使用本软件前仔细阅读并充分理解本政策。**您访问、安装或使用本软件，即视为您已阅读、理解并同意受本政策的全部内容约束。** 如您不同意本政策的任何内容，请立即停止使用本软件。

## 一、适用范围

本政策适用于您通过现代 Web 浏览器访问或以渐进式 Web 应用（PWA）形式安装并使用 Chronos 时，本软件对您信息的处理行为。

本政策明确**不适用于**以下情形：

- 您通过已安装的数据源插件连接的第三方高校、教育机构或软件商官方系统（如教务系统、统一身份认证服务等）对您个人信息的处理行为；
- 您通过本软件跳转访问的第三方外部网站、镜像源或由您自行添加的外部插件 manifest 链接所指向的第三方服务；
- 您自行编译、私有化部署或由第三方二次修改分发的 Chronos 实例（自行部署者应依照适用法律另行制定并公布其自身的隐私政策）。

## 二、我们处理的信息类型与场景

本软件采用**本地优先（Local-First）**架构设计。除特定数据源插件可选的服务端代理中继请求及插件静态资源下载外，您的全部业务数据与个性化设置均默认存储于您本地设备的浏览器环境中，不会自动上传或同步至我们的中心化服务器。

### 2.1 您主动提供或本地生成的数据

| 数据类别 | 具体内容与场景 | 存储介质与位置 | 是否上传服务器 |
|----------|----------------|----------------|----------------|
| **课表与课程数据** | 课程名称、任课教师、上课地点、起止周次、星期节次、单双周规律、课程备注及自定义卡片颜色等（手动编辑、本地文件导入、口令解析或插件同步生成） | 设备本地 IndexedDB（`timetables` 表） | **否** |
| **学术教学配置** | 当前学期起始日、总周数范围、校区划分及各节次作息时间表 | 设备本地 IndexedDB（`timetables` 表） | **否** |
| **外观与交互偏好** | 亮色/暗色/跟随系统模式、已选颜色主题 ID、图标主题 ID、课表紧凑度布局、触感反馈开关等 | 设备本地 localStorage | **否** |
| **课表背景壁纸** | 用户主动选择上传的自定义图片或主题自带壁纸资源，以及裁剪比例、透明度、虚化度等视觉参数 | 设备本地 IndexedDB（`images` 表与 `preferences` 表） | **否** |
| **插件私有设置** | 已安装插件的个性化选项（如今日插件的课前准备提醒提前时间、日历插件的节假日展示偏好等） | 设备本地 IndexedDB（`pluginData` / `pluginBinary` 表） | **否** |
| **导入暂存数据** | 从各类途径导入课表在预览确认环节的临时数据草稿 | 设备本地 sessionStorage（标签页或浏览器关闭即销毁） | **否** |
| **本地解析文件** | 用户在设备上主动选取的二维码图片文件、教务 HTML 导出版文件等 | 仅在浏览器内存（RAM）中临时分析解码，操作结束即释放 | **否** |

**关于壁纸取色功能：** 当您在支持动态取色的主题中启用「壁纸取色」时，调色板计算程序完全在您本地设备的浏览器 Canvas 与内存中执行色彩聚类分析，提取主色调与课程调色板，**绝不会将您的壁纸图片上传至任何远程服务器**。

### 2.2 插件与扩展模块数据

本软件支持通过官方插件目录或外部 manifest 链接安装功能扩展。与此相关的数据处理遵循以下规则：

| 数据类别 | 说明 | 存储与处理位置 |
|----------|------|----------------|
| **插件清单与状态** | 插件标识符（`id`）、版本号、安装来源（Profile 预装、市场安装或外部链接）及启用状态 | 设备本地 IndexedDB（`officialPlugins` 存储） |
| **插件静态资源缓存** | 从官方 CDN 静态目录或您指定的 manifest URL 获取的代码 bundle（ESM）、样式表及主题配色 JSON | 经 SHA-256 完整性校验后缓存于设备本地，供浏览器运行 |
| **本地诊断工具数据** | 官方“错误日志”等开发辅助插件记录的应用运行时前端异常日志 | **仅存于设备本地**，供用户排查问题时主动查看或手动复制，**绝不会自动静默上传** |
| **时间模拟工具数据** | 官方“自定义时间”插件设定的虚拟时钟偏移量 | 仅存在于浏览器运行时内存中用于调试视图，不修改设备真实系统时钟 |

官方插件目录中的所有插件均经过静态安全审查，并随宿主发行包进行版本协同与 SHA-256 校验。若您从**外部链接**安装第三方插件，该代码在您的浏览器主线程环境中直接执行，具备访问本应用本地数据的同等能力，请您务必确保外部来源完全可信。

### 2.3 数据源插件在线导入涉及的信息

当您主动使用特定第三方数据源插件的“在线导入”功能直接从教务系统同步课表时，在您操作的单次会话期间可能涉及以下数据：

- **第三方账号（工号 / 学号）：** 用于向目标教学管理系统的认证入口表明用户身份；
- **认证凭据（密码 / 动态口令）：** 仅在您手动输入时临时存在于浏览器内存中，并在离开设备前进行端到端加密；
- **排课与教务原始数据：** 目标系统响应的课程列表、作息安排等，返回后在客户端本地解析为 Chronos 标准课程结构；
- **教学偏好：** 目标系统返回的校区绑定关系与排课日程。

### 2.4 通用插件服务端代理处理的数据

由于浏览器同源策略（CORS）限制，部分数据源插件需要通过 Chronos 提供的通用服务端代理网关（`/api/plugins/{pluginId}/{action}`）完成与第三方系统的跨域网络通信。在单次代理请求过程中，服务端可能接触以下数据：

| 信息类型 | 处理说明 | 是否在服务端持久化存储 |
|----------|----------|------------------------|
| **第三方账号与加密凭据** | 仅在服务端无状态内存中代向指定目标接口转发，请求完毕立即销毁 | **否（绝对不落盘、不入库、不写日志）** |
| **目标系统响应体** | 第三方系统返回的原始认证或课表数据，即时流式回传至前端 | **否（不留存任何副本或缓存）** |
| **客户端 IP 地址** | 仅用于内存级别的请求频次计数（Rate Limiting），防止接口被恶意攻击或滥用 | **否（仅内存短暂计数，定期重置，不记录访问明细）** |

### 2.5 使用情况统计（仅官方托管生产环境）

为了了解产品功能健康度、发现页面加载异常并持续优化用户体验，我们提供的**官方托管线上版**（在构建期配置了有效统计密钥的生产实例）集成了第三方分析服务 [PostHog](https://posthog.com/)。

**关于统计数据的严格限制与脱敏说明：**

- **仅限生产环境：** 本地开发环境、GitHub Pages 静态构建版以及未配置分析密钥的任何自建部署实例，**完全不包含**统计上报逻辑，构建器会自动剥离相关埋点代码。
- **关闭高危捕获功能：** 我们在 SDK 初始化时**彻底关闭了元素自动捕获（Autocapture）与用户会话录制（Session Recording）**，绝不记录用户的屏幕画面、输入过程或页面任意点击。
- **纯枚举事件设计：** 我们仅在用户触发关键流程时主动上报去标识化的功能事件（如：应用完成引导、课表导入完成、主题切换、PWA 更新触发、插件安装操作等），事件参数仅包含类型、状态枚举或耗时区间。
- **严格排除敏感业务正文：** 统计事件中**绝对不包含**您的课表名称、课程详情、授课教师、上课地点、备忘信息、账号学号或任何认证凭据。
- **插件埋点命名隔离：** 插件产生的埋点采用独立的 `plugin.{pluginId}.{action}` 命名空间，工具插件（如今日插件）仅记录提醒功能是否触发，绝不发送关联的课程内容。

| 收集项 | 说明 | 存储位置 |
|--------|------|----------|
| **功能事件与技术参数** | 功能操作枚举、界面路径切换、浏览器类型、操作系统版本、屏幕分辨率等技术元数据 | 发送至 PostHog 欧盟区域合规云服务器（`eu.i.posthog.com`） |
| **去标识化设备标识符** | 由 PostHog SDK 随机生成的 `distinct_id`，用于在无账号体系的前提下区分不同设备访问 | 设备本地 localStorage 及 PostHog 云端 |

### 2.6 我们明确承诺不收集的信息

本软件始终坚持数据极简主义，**绝不收集**以下信息：

- 用户的真实姓名、手机号码、电子邮件、身份证号等现实个人身份信息；
- 用户的地理位置（GPS / 基站定位）、设备通讯录、剪贴板监控、麦克风或摄像头数据；
- 任何形式的明文密码、银行卡信息或支付凭据；
- 用户在课表中记录的个人日程正文、学习生活备注或社交关系链。

## 三、第三方数据源认证凭据处理说明（重要）

本节专门详细说明当您使用数据源插件的在线导入功能时，本软件对第三方账号与认证凭据的最高安全标准处理流程：

### 3.1 本软件绝不持久化存储密码与凭据

**在任何时间、任何场景下，本软件绝不会在设备本地存储或服务端数据库中持久化保存您的第三方教务密码或核心认证凭据。**

具体安全流转过程如下：

1. **输入与内存阶段：** 您的账号与密码仅在您主动输入时临时存在于浏览器运行时的只读内存变量中，仅用于当次同步任务；
2. **端到端加密阶段：** 凭据在离开您的浏览器之前，客户端会依照目标系统的加密规范（如采用目标系统指定的 RSA/SM2 公钥）对密码进行非对称加密，网络传输的仅为密文；
3. **服务端无状态中继：** 服务端代理接口仅在单次 HTTP 请求的执行线程内存中代为中继请求。**请求执行完毕或超时中断后，内存立即垃圾回收，绝不将凭据、会话 Cookie 或中继数据写入数据库、持久化缓存或磁盘日志；**
4. **导入成果留存：** 解析完毕的课程日程存入您设备本地数据库，其中**绝不夹带任何账号凭据**；
5. **不提供自动保存：** 本软件不在本地记住第三方系统密码，每次在线同步均需您手动授权并即时输入。

### 3.2 第三方系统的独立责任

您通过数据源插件向目标学校或教育机构系统发起的认证与数据拉取，属于您与该第三方系统之间的独立行为。该等系统对您个人信息的处理受其自身的隐私政策与服务条款约束，我们建议您了解相关第三方系统的隐私规范。

## 五、信息的存储与安全保障

### 5.1 本地优先存储

您的核心数据均保存在您本地设备的浏览器内部：

- **IndexedDB：** 用于可靠存储课表、课程详情、节次设置、插件记录及自定义壁纸原图；
- **localStorage：** 用于保存轻量的主题模式、布局紧凑度、触感开关及分析 SDK 设备标识；
- **sessionStorage：** 用于数据导入时的临时步骤暂存。

**数据备份与容灾提示：** 由于本软件不设中心化用户数据库，数据完全依赖于您本地浏览器的存储机制。当您主动执行浏览器“清理所有历史数据/站点数据”、卸载 PWA 应用、更换终端设备或使用无痕隐私窗口浏览时，本地存储的数据可能会被永久清除且无法从服务器找回。**我们强烈建议您定期通过「分享课表」导出备份口令或二维码保存。**

### 5.2 安全防护措施

我们采取业界标准的技术手段保障信息安全：

- 全站强制启用 HTTPS / TLS 加密传输，防止数据在网络链路中被窃听或篡改；
- 第三方凭据在离开客户端前实施非对称加密；
- 服务端代理接口部署严格的 IP 速率限制与超时熔断策略，防止暴力探测；
- 官方插件资源经过严格的构建期沙盒隔离打包及 SHA-256 完整性哈希校验；
- 分析统计服务关闭所有高危捕获项，且在底层剥离课表正文与身份字段。

### 5.3 基础设施第三方服务商

本软件官方托管版部署于 Vercel 等合规云平台，静态资源通过内容分发网络（CDN）加速。这些云基础设施可能会在底层网络层记录基础访问日志（如客户端 IP、访问时间、请求路径），该等记录属于云服务商维持基础设施安全稳定的标准做法，由服务商依照其自身合规体系管理。

## 六、信息的共享、流转与披露

我们绝不出售、出租或交易您的任何个人信息。我们仅在以下极其有限的情形下发生必要的数据流转：

1. **向目标教学管理系统发起请求：** 当您主动要求在线同步时，经您授权输入的学号与加密凭据将按第三方协议要求中继发送至对应的学校或机构官方认证系统；
2. **分析服务商（仅官方托管版）：** 去标识化的操作事件与客户端技术参数将传输至 PostHog 欧盟区域合规云服务器进行聚合统计分析；
3. **课表分享的端到端安全性：** 当您使用本软件的「分享课表」功能生成分享口令链接（如 `https://.../s#1.xxxxx`）时，课表压缩载荷被完整存放在 URL 的哈希（`#` Fragment）部分。根据国际 W3C 标准与 HTTP 协议规范，**URL 哈希内容完全由浏览器前端处理，绝不会随 HTTP 请求发送至任何 Web 服务器**，从而确保了分享内容在传输网络上的端到端私密性；
4. **法律与合规强制要求：** 仅在依照法律法规、司法判决、法定诉讼程序或政府主管机关具有法律效力的强制性命令要求时，我们才可能依法提供必要的信息。
